## Описание данных — Marketing Email Campaign Analysis

### 1. Структура данных
Исходный датасет содержит информацию о маркетинговых email-кампаниях, получателях и результатах взаимодействия с письмами.

Предполагаемая гранулярность: строка - отправленное клиенту письмо, в рамках маркетинговой компании.
### 2. Качество данных
#### Пропущенные значения
- Столбец Device на 50% пустой.
- Гипотеза: возможно, удаётся определить устройство клиента, только если он не открыл письмо.
- Пустые значения были заменены на 'Unknown'
#### Несогласованность данных
- Столбец Device содержит "table" и "Table".
- В данном случае, регистр не важен, было выполнено приведение к нижнему регистру.
#### Типы данных
- Clicked, Bounced, Opened, Unsubscribed, Conversion содержат только 0 и 1.
- Столбцы Country Latitude и Country Longitude, по умолчанию, имели текстовый тип данных. 
- Столбцы Country Latitude и Country Longitude были преобразованы в Decimal, без ошибок.
#### Повторяющиеся данные
- Существует 801 комбинация Campaign Name + Client Email + Date Sent
- Обнаружена 681 группа полностью идентичных строк.
- Максимальное количество строк с одинаковой комбинацией - 9.
